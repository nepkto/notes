## Troubleshooting Large Request Error on Nginx

If you encounter the following error in your Nginx logs:

```
client intended to send too large body: [size] bytes, client: [IP], server: [your-domain], request: "[METHOD] [URL] HTTP/1.1", host: "[your-domain]"
```

**Cause:**  
This error occurs when the client tries to upload or send a request body larger than the size permitted by Nginx.

**Solution:**  
To allow larger uploads or request bodies, increase the `client_max_body_size` directive in your Nginx configuration.

**You can set this directive inside the `http`, `server`, or `location` block.**

For example, to allow up to 10MB uploads for your whole site:
```nginx
server {
    listen 80;
    server_name demo.example.com.com;

    client_max_body_size 10M;

    # ... other configs ...
}
```

Or, for a specific location:
```nginx
location /admin/games/3 {
    client_max_body_size 10M;
    # ... other configs ...
}
```

1. Open your Nginx configuration file (usually `/etc/nginx/nginx.conf` or under `/etc/nginx/sites-available/`).
2. Add or update the `client_max_body_size` line as shown above.
3. Save the file and reload Nginx to apply changes:
    ```sh
    sudo nginx -t
    sudo systemctl reload nginx
    ```

**Note:**  
If you use upstream services (e.g., PHP, Node.js), ensure their upload limits are also configured to handle larger files.

For more information, see the official [Nginx documentation](https://nginx.org/en/docs/http/ngx_http_core_module.html#client_max_body_size).
