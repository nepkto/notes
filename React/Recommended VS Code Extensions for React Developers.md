# Recommended VS Code Extensions for React Developers

A curated list of Visual Studio Code extensions to enhance productivity, code quality, and workflow for React development.

---

## UI/JSX Enhancements

- **[ES7+ React/Redux/React-Native/JS snippets](https://marketplace.visualstudio.com/items?itemName=dsznajder.es7-react-js-snippets)**  
  Quickly scaffold components, hooks, Redux; lots of handy code snippets.
  
- **[Reactjs Code Snippets](https://marketplace.visualstudio.com/items?itemName=xabikos.ReactSnippets)**  
  Popular snippet pack for React development.

---

## Linting & Formatting

- **[ESLint](https://marketplace.visualstudio.com/items?itemName=dbaeumer.vscode-eslint)**  
  JS/JSX linter for real-time code style and error checking in the editor.

- **[Prettier - Code formatter](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)**  
  Opinionated code formatter with wide adoption; ensures consistency.

---

## Intellisense & Tooling

- **[Auto Import](https://marketplace.visualstudio.com/items?itemName=steoates.autoimport)**  
  Automatically adds missing ES6 imports.

- **[Tabnine AI Autocomplete](https://marketplace.visualstudio.com/items?itemName=TabNine.tabnine-vscode)**  
  AI-powered code completions.

- **[Path Intellisense](https://marketplace.visualstudio.com/items?itemName=christian-kohler.path-intellisense)**  
  Autocomplete filenames and file paths while you type.

- **[Import Cost](https://marketplace.visualstudio.com/items?itemName=wix.vscode-import-cost)**  
  Displays the size of the imported package inline.

---

## Testing & Debugging

- **[Jest](https://marketplace.visualstudio.com/items?itemName=Orta.vscode-jest)**  
  Run and debug Jest tests directly from VS Code.

- **[Debugger for Chrome](https://marketplace.visualstudio.com/items?itemName=msjsdiag.debugger-for-chrome)**  
  Debug React apps in Chrome from within VS Code.

---

## Styling

- **[Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)**  
  Autocomplete, syntax highlighting, and linting for Tailwind CSS.

- **[Styled Components](https://marketplace.visualstudio.com/items?itemName=styled-components.vscode-styled-components)**  
  Syntax highlighting and IntelliSense for Styled Components.

---

## Productivity & Miscellaneous

- **[GitLens](https://marketplace.visualstudio.com/items?itemName=eamodio.gitlens)**  
  Git visualization and tracking, inline blame, and more.

- **[Bracket Pair Colorizer 2](https://marketplace.visualstudio.com/items?itemName=CoenraadS.bracket-pair-colorizer-2)**  
  Colors matching brackets for easy readability.

- **[Code Spell Checker](https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker)**  
  Highlights common spelling errors in your codebase.

- **[Prettier Now](https://marketplace.visualstudio.com/items?itemName=remimarsal.prettier-now)**  
  Format on save, auto-fix your code.

---

## Bonus: Specialized for React

- **[React PropTypes Generate](https://marketplace.visualstudio.com/items?itemName=mrmlnc.vscode-prop-types)**  
  Quickly generate PropTypes from component definitions.

- **[Simple React Snippets](https://marketplace.visualstudio.com/items?itemName=burkeholland.simple-react-snippets)**  
  Lightweight snippets focused on React.

---

### How to Install

- Open the VS Code Extensions sidebar (`Ctrl+Shift+X` or `Cmd+Shift+X`).
- Search for the extension by name, or paste the **extension ID** from the links above.

---

_You can tailor this list further for tools like Redux, TypeScript, or advanced state management as your project grows!_
